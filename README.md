# Keira's Kook Book

A phone-friendly cookbook for kids ages 4–10. Tap a food photo to see the picture, ingredients, and a few easy steps.

**Live page:** https://xburbx620.github.io/keiras-kook-book/

Recipes are short, healthy, and meant to be made with a grown-up for knives, the stove, and the oven.

## Open the app

From this folder:

```bash
py -3 -m http.server 8088
```

Then visit [http://localhost:8088](http://localhost:8088).

You can also double-click `index.html`.
